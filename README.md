# Student Job Portal

A web-based Student Job Portal developed using Python and Django.

## About the Project
The Student Job Portal helps students explore job opportunities, view job details, and track their job applications.

## Technologies Used
- Python
- Django
- SQL / SQLite
- HTML
- CSS
- Git and GitHub

## Features
- Student Login and Logout
- Student Dashboard
- Student Profile Management
- Job Listings
- Job Details
- Apply for Jobs
- My Applications
- Application Status Tracking
- Job Search and Pagination

## Installation

1. Clone the repository.
2. Install the required packages:

   `pip install -r requirements.txt`

3. Run migrations:

   `python manage.py migrate`

4. Start the development server:

   `python manage.py runserver`

5. Open `http://127.0.0.1:8000/` in your browser.
